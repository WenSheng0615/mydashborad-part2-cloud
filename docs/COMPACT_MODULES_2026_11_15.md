# 2026-11-15 App 管理精簡版面

依使用者手機截圖回饋，把模組管理由大型說明卡改為精簡 App 清單。

- 移除重複標語及常駐長提示，保留一行用途說明。
- 搜尋搭配重新整理圖示，狀態篩選集中為三段控制。
- 清單每列僅保留圖示、名稱、來源類型、詳細資料入口及啟用開關。
- 詳細描述與服務連線仍在原有詳細視窗可查看，未移除功能。
- 儲存結果簡化為「已儲存」，資料保留政策集中在頁尾。
- 保留原有權限、模組設定、關閉不刪資料的行為，不更動外部服務授權。

驗證：隔離 SQLite 的瀏覽器回歸測試通過，涵蓋搜尋／篩選／儲存／詳細連線及既有資料保留；390px 下每列高度不超過100px、首屏至少可看到3個 App。另有320–1440px既有全站版面檢查。
